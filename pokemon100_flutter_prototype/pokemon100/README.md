# Pokémon 100% — Flutter prototype

Pierwszy działający szkielet aplikacji zgodny z dotychczasowym pomysłem: responsywny interfejs, nawigacja, dashboard, poradnik, Pokédex, Team Matching, osiągnięcia, LAB i profil.

## Wymagania
- Flutter 3.19+
- Dart 3.3+

## Uruchomienie
```bash
flutter pub get
flutter run
```

Na Windows:
```bash
flutter run -d windows
```

Na Android:
```bash
flutter run -d android
```

Na web:
```bash
flutter run -d chrome
```

## Uwaga
W tym środowisku Flutter SDK nie jest zainstalowane, więc kod został przygotowany jako kompletna aplikacja Flutter, ale nie mogłem wykonać lokalnego `flutter run`/`flutter test`.
